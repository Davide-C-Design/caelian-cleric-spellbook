# Caelian Cleric Spellbook

A responsive, standalone D&D 3.5 Cleric spellbook for Caelian Vàel. It includes the Cleric, Magic Domain, and Balance Domain spell lists, preparation tracking, bookmarks, spell details, and editable Cleric level and Wisdom values.

## Use locally

Open `index.html` in a modern browser. No install, build step, or server is required.

## Notes

- Prepared spells, bookmarks, level, and Wisdom are saved in the browser when local storage is available.
- The spellbook remains usable offline; external rules-reference links require an internet connection.
- Balance Domain entries retain links to their source instead of reproducing proprietary book text.
